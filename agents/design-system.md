# Design system

Consulte [../docs/padro-visual.md](../docs/padro-visual.md) antes de criar ou alterar uma tela. Este arquivo concentra decisões reutilizáveis de design; o documento em `docs` é a referência completa para produto e revisão visual.

Regra de ouro: clareza, espaço e consistência antes de ornamentação.

O produto é uma aplicação local multiusuário com uma interface compartilhada. Gestão de contas e permissões pertence às Configurações; não criar layout, dashboard ou navegação separados para administração.
